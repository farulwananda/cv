Compiling static HTML at build time and hydrating only isolated interactive leaves keeps the initial JS payload under 40kB. 

Pairing this with `stale-while-revalidate` edge caching makes pages feel instantaneous worldwide, eliminating both client hydration churn and server cold-start delays.

```javascript
export async function GET({ request }) {
  const renderedHtml = await renderStaticPage();

  return new Response(renderedHtml, {
    headers: {
      'Content-Type': 'text/html; charset=utf-8',
      'Cache-Control': 'public, max-age=60, s-maxage=3600, stale-while-revalidate=86400',
      'CDN-Cache-Control': 'max-age=86400',
      'Vary': 'Accept-Encoding',
    },
  });
}
```
