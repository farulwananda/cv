Switching from row-oriented storage to ClickHouse columnar MergeTree tables with ZSTD compression yielded a 10x reduction in disk footprint for event telemetry. 

Because queries only scan and read the specific columns requested (e.g., `duration_ms`, `status_code`), analytical aggregations over 50M rows complete in less than 180ms.

```sql
CREATE TABLE default.telemetry_stream (
    event_time DateTime64(3, 'UTC') CODEC(DoubleDelta, ZSTD(1)),
    endpoint LowCardinality(String) CODEC(ZSTD(3)),
    status_code UInt16 CODEC(T64, ZSTD(1)),
    duration_ms Float32 CODEC(Gorilla, ZSTD(1)),
    payload_bytes UInt32 CODEC(T64, ZSTD(1))
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(event_time)
ORDER BY (endpoint, event_time);
```
