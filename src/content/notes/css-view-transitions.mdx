The native View Transitions API gives multi-page web applications seamless app-like animations without the bloat, complexity, and memory overhead of a full Single Page Application framework. 

By letting the browser orchestrate the DOM snapshot cross-fade, JavaScript bundles stay lean.

```css
@view-transition {
  navigation: auto;
}

::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 200ms;
  animation-timing-function: cubic-bezier(0.16, 1, 0.3, 1);
}

::view-transition-old(root) {
  opacity: 0;
  transform: translateY(-4px);
}

::view-transition-new(root) {
  opacity: 1;
  transform: translateY(0);
}
```
