Using `sync.Pool` for high-throughput byte slices drastically cuts GC pauses. In high-frequency telemetry ingestion workers, reusing allocated byte buffers in the hot path was the single biggest factor in keeping P99 latency strictly under 5ms. 

Without object pools, short-lived byte slices trigger frequent stop-the-world scavenges under heavy 10k req/s ingestion load.

```go
package main

import (
	"io"
	"sync"
)

var bufferPool = sync.Pool{
	New: func() any {
		b := make([]byte, 4096)
		return &b
	},
}

func ProcessStream(r io.Reader) error {
	bufPtr := bufferPool.Get().(*[]byte)
	defer bufferPool.Put(bufPtr)
```
